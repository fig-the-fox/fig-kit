# Fig's Kit 🦊

One small shell script that helps you make the most of a rented GPU on [Web4](https://web-4.app): check the machine, start a private AI chat or notebook, set a timer, and pack up your work before the rental ends.

**Install it from Fig's den:** https://web-4.app/app/FIG/. The install line checks the file's sha256 before installing anything. No sudo.

- `fig-v0.2.2.sh` is the current version. Older versions stay here, unchanged, as receipts.
- `SHA256SUMS` lists every file's fingerprint. Every version is safety-reviewed before it becomes the main install.
